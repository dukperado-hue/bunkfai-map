# บั๊งบึงไฟประเทศไทย — แผนที่ประกาศรายจังหวัด 77 จังหวัด + กทม. (GIS)

Bun Bang Fai (บั๊งบึงไฟ) Thailand provincial regulation map. แสดงประกาศ/ระเบียบเกี่ยวกับการจุดและปล่อยบั๊งบึง พลุ ตะไล โคมลอย โคมไฟ โคมควัน ของทุกจังหวัด (77 จังหวัด + กทม.) พร้อมชั้นข้อมูลเขตปลอดัยทางการเดินอากาศของทุกสนามบิน (AIP CAAT AIRAC 2026-07-09)

เป็นการพัฒนาต่อจาก repo เดิม `birdheatmap` โดยเปลี่ยนจากข้อมูลนกชนเครื่องบินเป็นข้อมูลกฎหมายบั๊งบึงไฟรายจังหวัด

## โครงสร้าง

- `web/index.html` + `web/app.js` — ผัง Leaflet แบบ offline (เปิดจาก file:// ได้) ด้านข้างมีการเลือกภาค → จังหวัด → การ์ดประกาศ + รายการ 43 สนามบินพร้อมโซนปลอดัย
- `web/data.js` — ข้อมูลทั้งหมด inlined (PROVINCES, PROV_REF, PROV_DATA, AIRPORTS) จึงไม่มี fetch — เหมาะสำหรับ GitHub Pages และเปิดไฟล์ตรง
- `web/vendor/` — Leaflet (js/css)
- `data_prep/` — pipeline สร้าง `web/data.js` จากไฟล์ JSON ต้นฉบับ
  - `enhance_airports.py` — เพิ่มจังหวัด + โซนปลอดัย (LHZ 10 กม. + แนวรันเวย PHZ) ให้รายการสนามบิน
  - `build_data_js.py` — รวมข้อมูลทั้งหมดเป็น web/data.js
- `gee/bunbangfai_regulation_map.js` — Earth Engine Code Editor script เทียบเท่า (ใช้ FAO/GAUL level1 + ARP buffer 10 กม.) สำหรับผู้ที่มีบัญชี GEE

## ข้อมูลที่ใช้

| ชั้นข้อมูล | แหล่ง |
|---|---|
| เขตจังหวัด (77) | GADM level-1 (รวมบึงกาฬจาก geoBoundaries CGAZ) |
| ประกาศรายจังหวัด | OIC CABINFOCENTER, ราชกิจจานุเบกษา, เว็บไซต์จังหวัด (สรุปเป็น PROV_DATA) |
| พิกัด + ชื่อสนามบิน (43 ARP) | AIP CAAT eAIP, AIRAC cycle 2026-07-09 (AD 1.3 / AD 2) |
| เขตปลอดัยทางการเดินอากาศ | ประกาศเขตปลอดัยในการเดินอากาศ (พ.ร.บ.การเดินอากาศ พ.ศ. 2497) — โมเดลวงกลม 10 กม. + แนวรันเวย |

## วิธีใช้

```bash
python3 data_prep/build_data_js.py   # สร้าง web/data.js
# เปิด web/index.html ในเบราว์เซอร์ หรือ deploy บน GitHub Pages
```

## หมายเหตุ

- ข้อมูลประกาศใน `web/data.js` (PROV_DATA) เป็น "สรุป" — หลายจังหวัดยังไม่ได้ตรวจสอบต้นฉบับทีละจังหวัด (ดูฟิลด์ `verified`) ควรอ้างอิงต้นฉบับจากลิงก์ `sourceUrl` ก่อนนำไปใช้ทางกฎหมาย
- สนามบินทางทหารบางแห่งไม่รวมในรายการ
- GeoJSON จังหวัดผ่านการ simplify (tolerance 0.008) เพื่อลดขนาดไฟล์ — ขอบเขตไม่เหมาะสำหรับงานสำรวจที่ต้องการความแม่นยำระดับเมตร
